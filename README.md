# 🌐 DIGITAL FRONTIER
### Measuring Digital Development Across Economies

**📊 A Business Analytics Project Using Power BI and the ICT Development Index (IDI) 2026**

---

## 📌 Project Overview

Digital connectivity plays a vital role in economic growth, access to information, education, and participation in the digital economy. However, digital development is not equally distributed across economies.

**DIGITAL FRONTIER** is a data analytics and visualisation project that examines digital development across economies using the **ICT Development Index (IDI) 2026**, published by the International Telecommunication Union (ITU).

The project uses descriptive analytics and interactive Power BI visualisations to explore regional differences, compare income groups, and identify patterns in digital connectivity.

🎯 **The main objective is to transform complex data into meaningful insights that help explain global digital-development disparities.**

## 🎯 Project Objectives

- 📈 Analyse ICT Development Index scores across economies.
- 🌍 Compare digital development across geographical regions.
- 💰 Examine differences in IDI scores among income groups.
- 🔎 Identify disparities in digital connectivity and development.
- 📊 Build an interactive Power BI dashboard for data exploration.
- 💡 Communicate analytical findings through clear and effective visualisations.

## 📂 Dataset

The project uses a cleaned dataset derived from the International Telecommunication Union's ICT Development Index 2026 resources.

**Dataset coverage:** 158 economies in the project analysis.

### 🔑 Key Variables

The dataset includes indicators relating to:

- 🌐 Internet usage and household internet access
- 📱 Mobile phone ownership
- 📡 Mobile broadband subscriptions
- 📶 3G and 4G/LTE network coverage
- 📊 Mobile and fixed broadband traffic
- 💵 Broadband affordability indicators
- 🌍 ITU geographical regions
- 💰 World Bank income groups
- 📈 Universal Connectivity Pillar Score
- 🔗 Meaningful Connectivity Pillar Score
- 🏆 ICT Development Index score and rank

Some indicator fields contain missing observations, which should be considered when interpreting the analysis.

### 🔗 Official Data Source

**International Telecommunication Union (ITU)**

[Explore the ICT Development Index 2026](https://www.itu.int/itu-d/reports/statistics/IDI2026/)

## ⚙️ Methodology

The project follows a structured descriptive analytics workflow.

1. **📥 Data Collection:** Obtain the relevant ICT Development Index dataset from ITU resources.
2. **🧹 Data Preparation:** Inspect the dataset and select relevant variables.
3. **🔧 Data Cleaning:** Review missing values, remove unnecessary fields where appropriate, and prepare the data for analysis.
4. **🔍 Exploratory Analysis:** Examine IDI scores across geographical regions and income classifications.
5. **📊 Dashboard Development:** Build Power BI visualisations to present key indicators and comparisons.
6. **💡 Interpretation:** Identify patterns and disparities while acknowledging the limitations of the dataset.

## 📊 Dashboard and Visualisations

The Power BI dashboard provides a comparative overview of digital development across the economies included in the analysis.

### Key Dashboard Components

- **📌 KPI Cards:** Summarise key indicators, including the average IDI score, highest observed score, and number of economies analysed.
- **🌍 Regional Comparison:** Compare average IDI scores across six ITU geographical regions.
- **💰 Income Group Analysis:** Examine differences in digital development across income classifications.
- **🥧 Regional Distribution:** Show how the economies in the dataset are distributed across geographical regions.
- **🔗 Correlation Analysis:** Explore the association between income classification and digital development.
- **🎛️ Interactive Filters:** Support focused exploration of categories where implemented in the dashboard.

Each visualisation serves a distinct purpose, helping viewers understand the data from different analytical perspectives.

## 🔍 Key Findings

The following findings are based on the project's analysis-ready dataset.

### 🌐 1. Overall Digital Development

The average IDI score across the 158 economies in the project dataset is approximately **62.62**. This provides a summary of the digital development represented in the sample.

### 🌍 2. Regional Differences

| Region | Average IDI Score |
|---|---:|
| 🇪🇺 Europe | 76.81 |
| 🌏 Asia-Pacific | 67.82 |
| 🌐 CIS | 65.75 |
| 🌎 Americas | 57.45 |
| 🕌 Arab States | 56.36 |
| 🌍 Africa | 45.45 |

**Key Insight:** Europe records the highest regional average at 76.81, while Africa records the lowest at 45.45. The difference between these averages is **31.36 points**, highlighting substantial regional disparities.

### 💰 3. Income Group Differences

| Income Group | Average IDI Score |
|---|---:|
| High income | 80.55 |
| Upper-middle income | 64.66 |
| Lower-middle income | 47.60 |
| Low income | 28.38 |

**Key Insight:** High-income economies have an average score of 80.55, compared with 28.38 for low-income economies. The difference is approximately **52.17 points**.

These findings indicate an association between income classification and digital development, but they do not establish that income alone causes higher IDI scores.

### 🗺️ 4. Regional Sample Distribution

The dataset includes economies from six geographical regions. Europe contributes the largest number of observations, while the CIS region contributes the smallest.

This distribution is important when interpreting regional comparisons because the number of economies represented varies between regions.

## ⚠️ Limitations

- The project analyses 158 economies in its prepared dataset; this is not necessarily the total coverage of the official ITU publication.
- Some indicator variables contain missing observations.
- Regional and income-group averages can conceal differences between individual economies.
- Descriptive analysis does not establish causal relationships.
- Correlation results depend on the variables, encoding, and observations used in the calculation.
- The findings reflect the definitions and coverage of the available dataset.
